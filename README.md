# 📊 Customer Support Chat Optimization – Business Analyst Project

## 🔷 Project Overview
This project focuses on analyzing customer support chat data to identify inefficiencies in response handling and improve overall customer satisfaction. The objective was to simulate a real-world business scenario and apply Business Analyst methodologies to derive actionable insights using data analysis and visualization tools.

---

## ❗ Problem Statement
Customer support operations often face multiple challenges:
- High average response time  
- Delayed issue resolution  
- Inconsistent agent performance  
- Low customer satisfaction (CSAT) scores  

These issues negatively impact customer experience and operational efficiency. This project aims to identify the root causes and provide data-driven recommendations.

---

## ⚙️ Approach
- Created a **simulated business scenario** based on industry practices and customer service experience  
- Identified key stakeholders: Customer Support Managers, Operations Team, End Users  
- Documented requirements using a **Business Requirements Document (BRD)**  
- Collected and cleaned dataset (chat logs, timestamps, CSAT scores)  
- Performed exploratory data analysis using **Excel and SQL concepts**  
- Built an interactive **Power BI dashboard** to track KPIs  
- Derived insights and proposed actionable recommendations  

---

## 🛠️ Tools & Technologies Used
- **Power BI** – Data visualization and dashboard creation  
- **Power Query** – Data cleaning and transformation  
- **DAX** – Calculated measures and KPIs  
- **Microsoft Excel** – Data preprocessing and analysis  
- **SQL (concepts)** – Data querying and trend analysis  
- **MS Visio** – Process flow diagrams  
- **BRD Documentation** – Requirement gathering and structuring  

---

## 📈 Key Outcomes
- Identified peak hours contributing to high response time  
- Highlighted performance differences among support agents  
- Established a relationship between response time and CSAT scores  
- Recommended optimized agent allocation during high-traffic periods  
- Suggested predefined response templates to reduce handling time  
- Proposed training improvements for underperforming agents  

---

## 📊 Dashboard Insights (Power BI)
The dashboard includes:
- KPI Cards: Average Response Time, Resolution Time, CSAT Score  
- Trend Analysis: Response time over time  
- Agent Performance Breakdown  
- Peak Hour Analysis  

---

## 💡 Key Learnings
- Applied Business Analyst methodologies in a simulated environment  
- Improved skills in data analysis and visualization  
- Learned to convert business problems into data-driven insights  
- Gained understanding of customer support KPIs and performance metrics
